# ebooks

Generates EPUB ebooks from Nachlass markdown files using Pandoc. Handles metadata extraction, page-ref stripping, and cover image conversion.

Multi-part works (W-RFM, W-PG, W-GB, W-ROC, W-RPP) are merged into a single EPUB with each part as a chapter. The individual part files are skipped when running `--all`.

## Usage

```
cargo run -- --all
cargo run -- --file Ms-116.md
```

## Options

- `--input` -- markdown directory (default: `../../md`)
- `--output` -- output directory for EPUB files (default: `../../epub`)
- `--covers` -- directory with SVG cover images from the covers tool (default: `../../covers`)
- `--file` -- generate a single ebook
- `--all` -- generate ebooks for all files
- `--pandoc` -- path to pandoc binary
- `--rsvg-convert` -- path to rsvg-convert binary

## Dependencies

- [Pandoc](https://pandoc.org/) for markdown-to-EPUB conversion
- [rsvg-convert](https://wiki.gnome.org/Projects/LibRsvg) (`brew install librsvg`) for SVG cover-to-PNG conversion
- Cropped SVGs in `../../graphics-cropped/` (generated by the graphics tool)
