# pdfs

Generates PDF files from Nachlass markdown files using Pandoc with the WeasyPrint PDF engine. Builds a custom CSS stylesheet with embedded TeX Gyre Pagella (body) and SangBleu Empire (headings) fonts, and an HTML template for consistent styling.

Multi-part works are merged into a single PDF with chapter headings, like the ebooks tool.

## Usage

```
cargo run -- --all
cargo run -- --file W-PI.md
```

## Options

- `--input` -- markdown directory (default: `../../md`)
- `--output` -- output directory for PDF files (default: `../../pdf`)
- `--covers` -- directory with SVG cover images from the covers tool (default: `../../covers`)
- `--file` -- generate a single PDF
- `--all` -- generate PDFs for all files
- `--pandoc` -- path to pandoc binary
- `--font-dir` -- directory with TeX Gyre Pagella OTF files
- `--heading-font-dir` -- directory with SangBleu Empire WOFF2 files

## Dependencies

- [Pandoc](https://pandoc.org/) for markdown-to-PDF conversion
- [WeasyPrint](https://weasyprint.org/) (`pip install weasyprint`) as the PDF engine
- Cropped SVGs in `../../graphics-cropped/` (generated by the graphics tool)
